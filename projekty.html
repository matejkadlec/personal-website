League Analysis

Pozastaveno

Webová aplikace pro analýzu League of Legends: historie zápasů, vývoj ranku a herní návyky na jednom místě, s experimentálními statistickými analýzami nad Riot API.

  • Přehled hráče s vývojem ranku, oblíbenými šampiony a rolemi
  • Historie zápasů s detailem každého hráče, buildy a runami
  • Analýza matchmakingu porovnávající spoluhráče se soupeři
  • Analýza posledních her v porovnání s dřívějšími hrami hráče
  • Sledování hráčů s plánovanými úlohami na pozadí

Technologie

  • Python
  • FastAPI
  • TypeScript
  • React
  • Next.js
  • PostgreSQL
  • Riot API

Warmane AddOns

Aktivní

Kolekce sedmi doplňků do World of Warcraft pro servery Warmane (Wrath of the Lich King 3.3.5a), napsaných v Lua nad původním API verze 3.3.5a.

  • Instance Tracker: historie a statistiky průchodů dungeonů s vyhledáváním, filtry, řazením a exportem do CSV
  • WG Reminder: upozornění před bitvou o Wintergrasp i během ní
  • Chat Copy: kopírování libovolné zprávy z chatu jedním kliknutím
  • Healer Mana a Healer Protection: varování skupiny při nedostatku many nebo aggru
  • Společný panel nastavení ve hře a příkazy pro každý doplněk

Technologie

  • Lua
  • WoW API 3.3.5a
