Warmane AddOns

Active

A collection of seven World of Warcraft add-ons for Warmane’s Wrath of the Lich King (3.3.5a) servers, written in Lua against the original 3.3.5a API.

  • Instance Tracker: dungeon run history and stats with search, filters, sorting and CSV export
  • WG Reminder: notices before and during Wintergrasp battles
  • Chat Copy: copy any chat message with one click
  • Healer Mana and Healer Protection: group warnings on low mana or aggro
  • A shared in-game settings panel and slash commands for every add-on

Tech stack

  • Lua
  • WoW API 3.3.5a
